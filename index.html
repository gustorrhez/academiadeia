Paso 1

¿Qué es HTML?

HTML (HyperText Markup Language) es el lenguaje que estructura toda página web. Funciona con etiquetas que le dicen al navegador qué mostrar.

🏗️

HTML — Estructura

Define el contenido: títulos, párrafos, imágenes, botones, formularios.

🎨

CSS — Estilo

Controla colores, tipografías, espaciados, animaciones y diseño responsive.

⚡

JavaScript — Interactividad

Agrega comportamiento: clicks, gráficas en tiempo real, fetch de APIs, etc.

📦

Un solo archivo .html

Puedes combinar los tres en un único archivo. Perfecto para dashboards rápidos.

Paso 2

Estructura base de un archivo HTML

Todo archivo HTML empieza con esta estructura mínima. Cópiala y tendrás una página lista para editar.

mi-pagina.html 
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Mi Primera Página</title>
  <style>
    /* Aquí va tu CSS */
    body { font-family: sans-serif; background: #1a1a2e; color: white; }
  </style>
</head>
<body>

  <h1>¡Hola Mundo!</h1>
  <p>Esta es mi primera página web.</p>

  <script>
    // Aquí va tu JavaScript
    console.log("Página cargada ✓");
  </script>
</body>
</html>

Paso 4

Código de un dashboard básico

Copia este código, ábrelo en tu navegador y tendrás un dashboard funcional al instante.

dashboard.html 
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8" />
  <title>Mi Dashboard</title>
  <style>
    body { font-family: sans-serif; background: #0d1117; color: #e0e0e0; padding: 2rem; }
    .grid { display: grid; grid-template-columns: repeat(3, 1fr); gap: 1rem; }
    .card { background: #161b22; border-radius: 12px; padding: 1.5rem; text-align: center; }
    .valor { font-size: 2.5rem; font-weight: bold; color: #6c63ff; }
    .etiqueta { color: #888; margin-top: 0.3rem; }
  </style>
</head>
<body>
  <h1>📊 Mi Dashboard</h1>
  <div class="grid">
    <div class="card">
      <div class="valor" id="v1">...</div>
      <div class="etiqueta">Ventas</div>
    </div>
    <div class="card">
      <div class="valor" id="v2">...</div>
      <div class="etiqueta">Usuarios</div>
    </div>
    <div class="card">
      <div class="valor" id="v3">...</div>
      <div class="etiqueta">Conversión</div>
    </div>
  </div>

  <script>
    // Simulación de datos (en producción vendría de una API)
    document.getElementById("v1").textContent = "$12,400";
    document.getElementById("v2").textContent = "348";
    document.getElementById("v3").textContent = "4.2%";
  </script>
</body>
</html>
Paso 5 — Despliegue

Publicar en GitHub Pages (gratis)

GitHub Pages te permite convertir cualquier repositorio en un sitio web accesible desde internet, sin pagar hosting.

Crear cuenta

Ve a github.com y crea una cuenta gratuita.

Nuevo repositorio

Clic en New repository. Ponle un nombre y márcalo como Public.

Subir tu archivo

Arrastra tu index.html al repositorio desde el navegador.

Activar Pages

Ve a Settings → Pages y selecciona la rama main como fuente.

¡Listo!

En segundos tendrás tu URL: tuusuario.github.io/mi-repo/

Alternativa con Git

Subir con comandos Git (para proyectos grandes)

Terminal 
# 1. Inicializar git en tu carpeta
git init

# 2. Agregar todos los archivos
git add .

# 3. Guardar cambios con un mensaje
git commit -m "Mi primera página web"

# 4. Conectar con tu repositorio de GitHub
git remote add origin https://github.com/TUUSUARIO/TUREPO.git

# 5. Subir el código
git push -u origin main
